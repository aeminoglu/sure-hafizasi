# Sûre Hafızası

Kur'an sûrelerinin adını, Mushaf'taki sırasını, âyet sayısını, ad anlamını ve Mekkî/Medenî oluşunu ezberlemek için soru-cevap uygulaması.

Telefona kurmak için GitHub Pages adresini Chrome ya da Samsung Internet ile açıp "Uygulamayı telefona yükle" düğmesine dokunun. İlk açılıştan sonra internetsiz çalışır.

Âyet sayıları Kûfe sayımına, Mekkî/Medenî ve nüzûl sırası Kahire Mushafı'na göredir. Yazı tipleri (Amiri, Figtree, Literata) SIL Open Font License ile dağıtılır.
